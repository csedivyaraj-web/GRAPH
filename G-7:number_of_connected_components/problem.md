# Number of Provinces

**Problem link:** [GeeksforGeeks — Number of Provinces](https://www.geeksforgeeks.org/problems/number-of-provinces/1)

## Topic
- Graphs
- DFS / BFS
- Connected Components

## Goal
Given an undirected graph represented by an adjacency matrix, count the number of provinces. A province is a group of vertices (cities) that are directly or indirectly connected.

## Reminder
Every isolated vertex is also its own province.

## complexity
time -> O(V)
space -> O(V)
